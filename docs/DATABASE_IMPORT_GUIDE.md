## 1. 先理解一件事

### 每件展品的"身份证"长什么样？

想象每件展品就像一个人，需要：
- **身份证号**（`id`）：唯一的编号，比如 `E01`、`E02`、`E35`
- **姓名**（`name_zh`）：展品的中文名称
- **个人简介**（`description_zh`）：展品的详细描述（100-500 字）
- **职业类别**（`category_zh`）：属于哪个类别
- **工作单位**（`source_museum_zh`）：来自哪个博物馆
- **专业标签**（`tags`）：1-3 个关键词标签

### ⚠️ 最容易搞混的两件事

**① `id` 编号的格式**
- 必须是 `E` + 两位数字，如 `E01`、`E12`、`E35`
- **不能重复**！每件展品必须有唯一编号
- 已经用到 `E35` 了，下一件新展品请用 `E36`

**② `name_zh` 名称的格式**
- ✅ 正确：`清代远洋商船船模`
- ✅ 正确：`明"乾隆"款珐琅蓝彩十三行通景画瓷碗`（带引号没问题）
- ❌ 错误：`明代水罗盘（中国航海博物馆）` ← 不要带括号里的博物馆名
- ❌ 错误：`明镇江兽 -> 调整为：明镇水兽` ← 不要写调整说明

**记住**：博物馆名有单独的字段 `source_museum_zh`，不要塞到名称里！

## 3. 表头说明（一列一列讲）

CSV 文件共有 16 列，但**你只需要填前 6-7 列**，其他的系统会自动生成！

### ✅ 必填列（一定要填）

| 列名 | 怎么填 | 示例 | 注意事项 |
|------|-------|------|---------|
| `id` | `E` + 两位数字 | `E01` | 不能重复，按顺序递增 |
| `name_zh` | 展品中文名 | `明代水罗盘` | 不要带括号里的博物馆名 |
| `description_zh` | 详细描述（100-500 字） | `水罗盘是中国古代航海最重要的定向仪器之一...` | 越详细匹配越准 |
| `category_zh` | 类别（见第 4 节） | `航海技术与仪器` | 必须是 6 个选项之一 |
| `source_museum_zh` | 来源博物馆 | `中国航海博物馆` | 全称 |
| `tags` | 1-3 个标签 | `指南针\|航海导航\|天文导航` | 用竖线 `\|` 分隔 |

### ⭐ 推荐填写列（让结果更准确）

| 列名 | 怎么填 | 示例 |
|------|-------|------|
| `exhibition_url` | 展览链接（可选） | 留空即可（系统使用统一链接） |

### 🤖 自动生成列（不用你填）

以下列**可以全部留空**，系统会自动生成：

| 列名 | 系统自动生成什么 |
|------|----------------|
| `name_en` | 英文名称（占位符，可后期替换） |
| `description_en` | 英文描述（占位符） |
| `source_museum_en` | 英文博物馆名 |
| `category_en` | 英文类别 |
| `tags_en` | 英文标签 |
| `historical_context_zh` | 历史背景（如果你已经有现成的可以填） |
| `historical_context_en` | 英文历史背景 |
| `related_courses` | 相关课程（基于类别自动推荐） |
| `related_keywords` | 关键词（从描述中自动提取） |

## 4. 类别的 6 个选项

`category_zh` 字段必须从下面 6 个选项中选 1 个，**不能自己造**：

| # | 类别名 | 适合的展品类型 |
|---|-------|--------------|
| 1 | `船舶结构与建造` | 船模、造船工具、船体构件 |
| 2 | `航海技术与仪器` | 罗盘、六分仪、海图、航标 |
| 3 | `港口与航运` | 港口模型、码头、海关、航运设施 |
| 4 | `海军与军事航海` | 军舰、武器、海军文物 |
| 5 | `海上贸易与文化` | 外销瓷、贸易文物、丝绸之路商品 |
| 6 | `航海人物与历史` | 航海家、历史事件、宗教建筑 |

**选哪个？** 想一下这件展品最核心的属性是什么。比如：
- 郑和雕像 → `航海人物与历史`（重点是人物）
- 郑和船队模型 → `船舶结构与建造`（重点是船）
- 外销瓷碗 → `海上贸易与文化`（重点是贸易）

## 5. 运行导入

### 步骤

**① 保存 CSV 文件**

在 Excel 里：`文件` → `另存为` → 格式选 **CSV UTF-8（逗号分隔）(`*.csv`)`**

⚠️ 不要保存为普通的 CSV（可能乱码），一定要选 UTF-8 版本。

**② 打开命令行**

Windows：按 `Win + R`，输入 `cmd`，回车

**③ 进入项目目录**

```cmd
cd C:\Users\你的用户名\Desktop\ICE\AI-Museum-Recommendation-System
```

（把"你的用户名"换成你电脑的实际用户名）

**④ 运行导入命令**

```cmd
python tools\import_exhibits.py templates\exhibits_minimal_template.csv
```

**⑤ 看输出**

成功的话你会看到类似：

```
📖 读取现有展品库：data\exhibits.json
   已有 35 件展品
📥 读取最小输入：templates\exhibits_minimal_template.csv
   读取到 2 条待导入记录

🔧 处理：E36 · 明代指南针
   ✅ 已新增展品 E36
      - 自动关键词：指南针, 罗盘, 航向, ...
      - 自动课程：船舶导航系统, 航海仪器, ...

🎉 完成！已保存 37 件展品到：data\exhibits.json
```

## 7. 交互式录入（更简单的方式）

如果你不想用 Excel 编辑 CSV，可以用问答方式录入：

```cmd
python tools\add_exhibit.py
```

程序会一步步问你：

```
展品编号 (例 E01)（选填，回车跳过） [E36]:
    → 直接回车（用默认的 E36）

展品中文名称 (例 清代水罗盘)（必填）:
    → 输入：明代指南针

展品详细描述 (100-500字，越详细匹配越准)（必填）:
    → 粘贴你的描述

展品类别（必填）:
    → 输入：航海技术与仪器

来源博物馆（必填）:
    → 输入：中国航海博物馆

专业标签 (用空格分隔，例 指南针 航海导航)（必填）:
    → 输入：指南针 罗盘 航向
```

然后程序会展示生成的完整记录让你确认，输入 `y` 保存。

## 8. 常见问题 FAQ

### Q1: 我只有 6 项必填信息，其他都空着能跑吗？

**能！** 系统会自动生成其他所有字段。

### Q2: 我填的 CSV 有 35 行，但只导入了 33 行？

可能是某两行的 `id` 重复了。检查 CSV：
- 每个 `id` 必须唯一（E01, E02, ... E35）
- 不要漏掉 `E` 前缀（不能写成 `01`，要写成 `E01`）

### Q3: 导入后网页上看不到新展品？

- 确认重启了 Streamlit：`Ctrl + C` 停止，再 `streamlit run app.py`
- 检查 `data\exhibits.json` 文件最后修改时间是不是刚才

### Q4: 描述太短会怎样？

- 少于 50 字：匹配效果会差（系统识别不出关键信息）
- 少于 100 字：能匹配，但推荐可能不准确
- **建议 100-500 字**

### Q5: 标签应该写什么？

- 写最能代表展品特征的 1-3 个词
- 用竖线分隔，如 `指南针|航海导航|天文导航`
- 也可以用空格分隔（程序会自动识别）

### Q6: 想改某件已有展品的信息？

打开 CSV，找到那行（按 `id` 查找），修改内容，重新运行导入命令。**会覆盖原有内容**。

### Q7: 想删除某件展品？

打开 `data\exhibits.json`，找到对应 `id` 的整段 `{...}`，删除它，保存。

### Q8: 图片怎么加？

- 位置：`assets\images\` 目录
- 命名：`E01_main.jpg`（主图）、`E01_thumb.jpg`（缩略图，可选）
- 没图片也没关系，系统会显示占位图标 🏺

### Q9: 英文字段全是乱码 / 占位符，要不要紧？

**不影响中文版！** 只有英文版会显示占位符。如果你只用中文版演示，可以完全不管。
需要真实英文翻译时：
- 免费方案：用 [DeepL](https://www.deepl.com/translator) 翻译后粘回 CSV 重新导入
- 付费方案：修改 `tools/import_exhibits.py` 调用翻译 API

### Q10: 我不小心搞坏了 exhibits.json 怎么办？

- 如果你用了 Git：`git checkout data/exhibits.json` 恢复
- 如果没用 Git：把模板 CSV 重新导入一遍就行
- **建议**：每次导入前备份一下 `data\exhibits.json`（复制一份叫 `exhibits_backup.json`）

## 📋 导入前检查清单

每次导入 CSV 前，对照这个清单：

- [ ] `id` 列：都是 `E##` 格式，没有重复
- [ ] `name_zh` 列：没有括号里的博物馆名，没有 "→ 调整为：" 这种备注
- [ ] `description_zh` 列：每条至少 100 字
- [ ] `category_zh` 列：都是 6 个选项之一
- [ ] `source_museum_zh` 列：都填了
- [ ] `tags` 列：每个展品 1-3 个标签，用 `\|` 或空格分隔
- [ ] CSV 保存为 **UTF-8 编码**
